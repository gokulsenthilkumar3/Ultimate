# Repository Cleanup Manifest

This document defines what belongs in the GrowthTrack workspace, what can be
regenerated and removed, and what must remain local without entering Git.

## Preserve in Git

These paths contain canonical source code, tests, configuration, or maintained
documentation.

| Path | Purpose |
| --- | --- |
| `growthtrack-ultimate/` | Canonical Ultimate UI, API, Prisma schema, desktop entry point, and tests |
| `FinSync/apps/web/` | Canonical FinSync web application |
| `FinSync/apps/mobile/` | Canonical FinSync mobile application |
| `FinSync/OxFin/` | Canonical independently runnable OxFin product and services |
| `Forex/` | Canonical Forex application, excluding the legacy nested copy noted below |
| `Family Connect/familyconnect/` | Canonical Family Connect frontend and backend |
| `Equity/NiftyLens/` | Canonical Equity/NiftyLens application |
| `scripts/` | Workspace launcher, gateway, and design-system synchronization |
| `tests/` | Cross-product and gateway tests |
| `.github/` | Continuous integration and deployment workflows |
| `.agents/` and `Claude/` | Repository-specific agent instructions and maintained automation assets |
| `docs/` | Architecture, verification, adapter, changelog, and archived decision records |
| Root `README.md`, `WORKSPACE.md`, `MIGRATION_GUIDE.md`, and `package.json` | Public documentation and workspace commands |
| Lockfiles and `.env.example` files | Deterministic installs and safe configuration templates |

The tracked `growthtrack-ultimate/.env.test` file is a synthetic test fixture.
It must contain test-only placeholder values and must never receive real provider
credentials.

## Preserve Locally but Git-ignore

These paths may be required on a developer machine, but can contain secrets,
personal information, large dependencies, or machine-specific state.

| Pattern or path | Reason |
| --- | --- |
| `.env` and `.env.*` except approved examples/test fixtures | Credentials and machine-specific service configuration |
| `*.db`, `*.sqlite`, `*.db-wal`, and `*.db-shm` | Personal application data and runtime caches |
| `growthtrack-ultimate/logs/` and `*.log` | Audit, session, server, and operational output |
| `node_modules/` | Installed JavaScript dependencies |
| `.venv/` | Installed Python environment |
| `.idea/` and `.vscode/` | Developer-specific editor settings |
| `.expo/` | Expo's local development state |
| Local uploads, exports, backups, and generated reports | Potentially private user content |
| Large downloaded model or market-data caches | Reproducible or machine-local data |

Do not remove local databases or logs as part of a routine cleanup. Back them up
first when a reset is explicitly required.

## Safe to Remove

These artifacts are regenerated by development, test, or build commands.

| Pattern | Regenerated by |
| --- | --- |
| `dist/` and `build/` | Production builds |
| `.next/` | Next.js development or production builds |
| `.vite/` | Vite dependency optimization |
| `.turbo/` and `.cache/` | Build tooling |
| `coverage/`, `.nyc_output/`, `playwright-report/`, and `test-results/` | Test runs |
| `__pycache__/`, `.pytest_cache/`, and `*.pyc` | Python and pytest |
| `growthtrack-release*/` | Electron desktop packaging |
| `.pnpm-store/` | Local package-manager cache |
| `*.tmp`, `*.temp`, `*.bak`, `*.old`, and stale startup logs | Temporary diagnostics |

The September 2026 cleanup removed all currently detected entries in this
category and reclaimed approximately 1.44 GB, including disposable dependencies
from the noncanonical legacy mobile tree.

## Review Before Removal

These paths look redundant or historical but still contain unique source or
documentation. They must not be deleted by an automated cleanup.

| Path | Current classification | Recommended decision |
| --- | --- | --- |
| `Forex/Forex-Ensemble-Prediction/` | Legacy nested Forex source, about 90 MB | Compare unique models and documentation, migrate anything still used, then archive or delete explicitly |
| `FinSync/Expense Tracker - Mobile/` | Separate older mobile application; about 0.72 MB of source plus installed dependencies | Confirm whether `FinSync/apps/mobile/` fully supersedes it before deleting the source tree |
| `docs/archive/` | Historical implementation records | Preserve unless formal documentation retention changes |
| Root planning files such as `feature.md`, `task.md`, `SPRINT.md`, and 3D plan HTML files | Historical planning material | Consolidate into `docs/archive/` before considering removal |
| `.replit` | Hosting/development configuration | Remove only if Replit support is officially retired |

## Cleanup Rules

1. Resolve every deletion target to an absolute path beneath the workspace.
2. Stop local services before deleting active build folders.
3. Never delete `.env`, databases, logs, uploads, or backups during routine cleanup.
4. Never delete a legacy source tree until its unique files have been migrated or intentionally discarded.
5. Keep `.gitignore` aligned with this manifest.
6. Run builds and tests after structural cleanup.
