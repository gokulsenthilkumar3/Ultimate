# Canonical thickness and diffusion study

Generated by scripts/parametric-portrait/build-thickness.mjs. Canonical geometry SHA-256 6627588660aa6c754aaa2edb181bc01a8ca60c3b4c534efa3e87f636ce5cda18 derives from the already recorded CC0 HM08/Anny basis. No photographs or measured skin scans are used.

thickness.png stores the neutral geometry's inward-normal exit chord, in millimetres. Starting epsilon is 0.00005 metres, only back-face exits are accepted, and values are capped at 60 mm. R/G encode unsigned 16-bit distance; B is a conservative hit-validity indicator. Load as linear data with flipY=false. This is whole-object geometry thickness, not dermal/epidermal layer thickness or a light-direction thickness measurement. Open boundaries, concavities and pose/identity changes limit its validity. Invalid hits do not enable thin-object scattering.

thickness-diffusion-lut.png is a project local-curvature irradiance preintegration using Burley's normalized two-exponential radial profile. The initial RGB profile d values are [1.2,0.55,0.3] mm (uncalibrated artistic defaults, not this person's measured coefficients). The curvature axis is 0..0.25 per mm; the cosine axis is -1..1. A normalized radial kernel samples a spherical normal field; it does not sample actual nearby surface irradiance, diffusion across a shadow boundary, or the path-traced Disney BSSRDF. The thickness response uses a bounded profile-tail redistribution, not a thin-slab transport solution.
