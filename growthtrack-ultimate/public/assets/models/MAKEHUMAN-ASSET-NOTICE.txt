humanoid-base.glb, humanoid-base-lite.glb, humanoid-adult-v2.glb and
humanoid-adult-v2-lite.glb are built from CC0 1.0 Universal
sources (licence status: VERIFIED, 2026-10-19):

- Body mesh and morph targets: makehumancommunity/makehuman v1.3.0
  (commit 1f508f6083b2f823dab15de924b3bde72e08d77c), base.obj and .target
  files. Its LICENSE.md states the assets "have been released under CC0 1.0
  Universal".
- Eyes, hair (short02) and skin textures: MakeHuman system assets pack
  makehuman_system_assets_cc0.zip; each file states "This asset was explicitly
  released as CC0 in september 2020".

No attribution is required under CC0; credit is given to the MakeHuman team and
Data Collection AB as a courtesy. Source project:
https://github.com/makehumancommunity/makehuman

Per-component sources, hashes and review dates are in ASSET-PROVENANCE.json
next to this file; archived licence texts and source manifests are in
docs/licenses/. Rebuild with npm run humanoid:fetch, npm run humanoid:compile
and scripts/build-makehuman-glb.py (see docs/ASSET_LICENCE_RESOLUTION.md).

Project-authored parts: the external-anatomy placeholder
(GrowthTrackPrivateAnatomy, generated by make_private_anatomy_mesh()), the
surface bakes from scripts/bake-geometry-surface.mjs, and the eye/hair
attachment from scripts/calibrate-humanoid-features.mjs and
scripts/repair-humanoid-feature-rig.mjs.

The adult-v2 derivatives retain the assessed body, facial assets, textures and
measurement sections. scripts/upgrade-human-attachments.mjs rebinds hidden
pelvic attachment tissue to body triangles, skin weights and body morphs.
This added binding is project-authored. It is not a scanned anatomy asset.
Rebuild derivatives with npm run humanoid:upgrade. Archived licence hashes and
the derivative-to-source hash chain are checked by npm run check:assets.
