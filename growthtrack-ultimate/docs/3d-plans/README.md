# Physique research and preview plans

Historical interactive model plans are owned by GrowthTrack Ultimate:

- [v2 model plan](v2Plan_3DModel.html)
- [v2 continuation](v2Plan_3DModelContinuation.html)
- [v3 human realism plan](v3Plan_HumanRealism.html)
- [v4 measurement and model preview](v4Plan_3DModel.html)

Open the HTML files locally. Their shared assets live in `plan-assets/`. These are research previews, separate from the authenticated Physique feature and its runtime models.

From `growthtrack-ultimate`, `npm run plan:model` regenerates the preview model and `npm run plan:viewer` regenerates the browser bundle. See [script instructions](../../scripts/README.md) for build dependencies. From the workspace root, run `npm run test:plan` to verify the relocated sources.

The latest [measurement plan](../HUMAN_REALISM_AND_MEASUREMENT_PLAN.md) remains the implementation reference. Model research is excluded from the general code-retrieval index to avoid spending context on generated assets and historical proposals.
