# GrowthTrack UI System V2

GrowthTrack combines WorkOS-style structure, Linear-like operational density, Bevel-inspired health presentation, and Bubbl-like expression only for onboarding, achievements, completion feedback, Action Center, and useful empty states.

## Reference matrix

- WorkOS: settings, forms, and information architecture.
- Linear: primary navigation, command search, tables, and dense workflows.
- Bevel: calm health metrics and daily summaries.
- Bubbl: brief expressive color and completion moments.
- Daybridge: approachable scheduling.
- Ghost: analytics hierarchy.

References guide principles; no branded assets are copied. The registered Inspo MCP server should be used in a fresh tool session to attach final captures and available `DESIGN.md` evidence.

## Rules

1. Users choose one of six product areas before scanning modules.
2. Neutral surfaces and one accent are the default; status colors remain semantic.
3. Forms use comfortable density; large tables may use compact density.
4. Glass is limited to navigation and temporary overlays.
5. Every screen supports keyboard navigation, 44px targets, reduced motion, forced colors, and 200% zoom.
6. Legacy styles are removed only after every consumer passes visual and behavior verification.

## Page templates

Command, Record, Analytics, Detail, Settings, and Immersive templates are the only approved page structures for migrated modules.
