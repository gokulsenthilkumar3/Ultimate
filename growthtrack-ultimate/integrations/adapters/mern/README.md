# Optional MERN adapter package

Generated by npm run adapters:sync. Keep the existing runtime.

**Stage:** architecture-template; not installed, deployed or production-ready.

React, Express and Node exist. MongoDB persistence is not installed; preserve existing SQL owners.

This package defines a read-only HTTP health boundary and acceptance contract. It does not implement a native database driver, AI generation protocol, compiler or cloud provisioning API. Implement domain-specific data methods and authentication behind the independently owned service before activation. Do not route owner records here by selecting a catalog entry.

The bridge accepts an exact server-configured HTTPS origin or literal loopback HTTP origin, bearer authentication if configured, bounded JSON, cancellation and no redirects. It exports no mutation or deployment function. Install this service's dependencies and pin a lockfile in its own environment; do not add unrelated runtimes to Ultimate.
