## What's in each file

**`scripts/validate-glb.js`** — zero dependencies, imports `MORPH_TARGET_NAMES` straight from your `constants.js` so it can never drift out of sync. Checks: vertex/tri count, full morph-target coverage, shader-only names wrongly baked as geometry, inert/unsculpted morph detection, Y-up orientation, joint count, orphaned buffer data, and PBR texture presence. Exit 0/1, so it's CI-safe. Add to `package.json`:
```json
"validate:glb": "node scripts/validate-glb.js"
```
and call it from `build` or a pre-commit hook once you want it enforced.

**`docs/BLENDER_HUMANOID_CHECKLIST.md`** — per-region vertex budgets and loop requirements, rigging checklist, shape-key rules (in order, with the shader-only exclusion), export settings, and a sign-off section that ends with running the validator.

**`docs/MORPH_TARGET_TABLE.md`** — full reconciliation of all three sources of truth (`MORPH_TARGET_NAMES`, `computeMorphWeights()`, Blender). It also surfaces two data-layer bugs unrelated to the GLB: 8 facial morphs are declared but never computed by the store, and `computeMorphWeights()` returns a `head_circumference` key that isn't declared anywhere — dead output. Those are `use3DStore.js` fixes, not Blender work.
