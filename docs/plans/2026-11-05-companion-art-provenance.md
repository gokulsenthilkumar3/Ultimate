# Companion illustration provenance

Generated 5 November 2026 using the imagegen tool from the three owner-supplied local reference photographs. Original photographs remain outside this repository. The generated illustration is an artistic likeness, not a photograph or identity-verification asset.

Output: `growthtrack-ultimate/public/assets/illustrations/personal-companion-v4.webp` (1254×1254, 166,514 bytes), with a 512×512 compact version (42,452 bytes). These are encodings of a generated transparent 2×2 atlas, using the existing local Sharp installation. No photo-editing script synthesized the artwork.

Generation brief: combine the owner's clear professional face, glasses, curly dark hair, short beard/moustache and relaxed outdoor expression into one consistent original illustrated companion. Sage overshirt, ivory T-shirt, small golden leaf pin; warm friendly expression, clean readable shapes, subtly dimensional clay-like shading. Transparent background. Four full-body poses in a strict 2×2 atlas: idle, greeting wave, attentive listening and celebration. Keep character scale/placement consistent and leave safe margins for sprite cropping. No text, logo, UI, photorealism or copied character design. Use the professional portrait as the primary facial reference, the relaxed photo for expression and the graduation photo for the golden accent.

The atlas is used on Welcome and in the explicit companion interface. It is not added to Login. CSS handles existing sprite poses, restrained water ripples and reduced-motion behavior. The three optional charm drawings and rope physics are original project code; neither installer artwork nor Hangly's collection is copied.
