# Local database console UI

The console on port 5556 now uses the Ultimate forest-green sidebar and light/dark workspace palette. Its view, styles and browser logic live in `growthtrack-ultimate/scripts/db-studio/`; `db-studio.mjs` embeds these local files into the response, including when proxied under `/db`. There are no external font requests or new runtime packages.

Included: source/provider status, table search and counts, filtering of the loaded page, bounded pagination, page/match-scoped CSV and JSON exports, schema inspection, provider-specific SQL templates, explicit query execution and a keyboard-accessible record drawer. Theme preference is stored locally. Source changes clear prior rows, query text and results; stale asynchronous responses cannot overwrite the new selection. CSV escaping handles embedded quotes/newlines and neutralizes spreadsheet formula prefixes. SQL renders at most 250 result rows with an explicit truncation message; this is a DOM bound, not a server query/response-size bound.

The existing source adapters, read-only transactions, routes, database files and schemas are unchanged. This work does not authorize writes or migrations.

A second UI pass increases table and control text sizes, adds comfortable/compact row spacing, pins row numbers during horizontal scrolling, and introduces a column chooser and accessible column-sort buttons. Sorts apply only to loaded rows, with null values last in both directions. Exports follow the filtered/sorted page and visible columns; resetting the view restores its default columns and order. Column choices reset on table/source changes, while density persists locally. The inspector can move through the current page's filtered/sorted records, search field names/values and copy complete record JSON, including fields hidden in the grid. Clipboard failures display a fallback message; the dialog traps keyboard focus and returns it to the inspected row on close.

Validation: the database-console API test and five synthetic DOM interaction tests cover read-only isolation, records, filtering, paging, exports, drawer focus, tabs, theme/density preference, empty/error recovery, stale source responses, SQL rendering limits, column visibility, page-local sorting, record navigation and clipboard feedback. The six gateway/proxy checks passed during the first pass. Browser automation was unavailable in this session; actual desktop/mobile layout and visual approval remain pending. DOM tests do not establish rendered coverage.
