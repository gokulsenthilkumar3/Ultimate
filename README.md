# FinSync One & GrowthTrack Ultimate 💰

A unified financial intelligence and personal operating system built as a modern, high-performance React application powered by Vite, TypeScript, and Tailwind CSS.

## 🚀 Key Features Ported

1. **FinSync & OxFin Command Center**:
   - Real-time cashflow metrics (Liquidity, Inflow, Outflow, and Portfolio Valuation).
   - Smart AI Financial Recommendation banner calculating monthly savings targets.
   - Interactive daily inflow vs outflow distribution charts.
   - Expense category breakdown with percentage allocations.

2. **Transaction Ledger & Tracking**:
   - Complete ledger with real-time add, categorize, search, filter (income, expense, bill), and delete capabilities.
   - Built-in CSV export for accounting and record keeping.

3. **Personal CFO Budget Planner**:
   - Threshold allocation models: 50/30/20 Standard, 70/20/10 High-Cost, 40/40/20 Balanced, and 60/20/20 Heavy-Needs.
   - Real-time needs/wants/savings spending progress meters and quotient diagnostics.

4. **Multi-Currency Wallets & Ox Crypto**:
   - Ox Full Wallet (6.5% APY compounding yield, interest projections, lock/unlock card freeze).
   - Wallet Lite with gold-pegged daily limit and PIN-free micro-payment controls.
   - Real-time Ox Crypto & 24K Gold exchange rate converter (USD, INR, EUR, GBP, Gold 1g, BTC, ETH).

5. **Investment Portfolio**:
   - Multi-asset tracking across Nifty 50 Index Fund, Bitcoin ETF, Equities (Reliance, AAPL), and Sovereign Gold Bonds.
   - Interactive SVG sparklines, live returns calculation, and simulated buy/sell execution.

6. **Bills & Subscriptions**:
   - Upcoming bill reminders, auto-pay tags, one-click settlement, and recurring bill creation.

7. **Card Management**:
   - 3D titanium FinSync One Platinum card visualization with lock/freeze toggle, spending progress, and channel security.

8. **Forex Ensemble Prediction Engine**:
   - Multi-factor ML directional signals (EUR/USD, GBP/USD, USD/JPY, USD/INR, AUD/USD).
   - Technical indicators (RSI-14, MACD, Moving Averages) and macro scenario sensitivity simulator.

9. **Security & Regional Preferences**:
   - Two-Factor Authentication (2FA / MFA) setup modal with authenticator code verification.
   - Multi-currency locale preferences (INR ₹, USD $, EUR €, GBP £, JPY ¥) adapting all balances immediately.

## 🛠️ Technology Stack

- **Framework**: React 18 + Vite 6
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Storage**: Ephemeral local storage with state synchronization

## 🏃 Getting Started

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Build production bundle
npm run build
```
